# 低配置服务器性能优化方案

## 📊 服务器配置分析

**服务器配置**：2核2G
- **CPU**：2核（处理能力有限）
- **内存**：2GB（需要精简内存占用）
- **瓶颈**：数据库查询、并发处理

## 🎯 优化目标

1. **减少数据库查询次数**：题目一次性加载到前端
2. **降低服务器压力**：前端缓存+轻量级API
3. **提升用户体验**：即时反馈，无需等待
4. **节省服务器内存**：减少数据库连接和缓存占用

## 🏗️ 架构设计方案

### 方案对比

| 方案 | 传统模式 | 优化模式 |
|------|---------|---------|
| **题目加载** | 每次请求查询数据库 | 一次性批量加载到前端 |
| **答题判题** | 后端查询数据库 | 前端即时判题 |
| **数据提交** | 每题提交一次 | 批量提交或离线提交 |
| **数据库访问** | 高频访问 | 低频访问（仅在必要时刻） |
| **服务器压力** | 高 | 低 |

### 优化架构图

```
┌─────────────┐                 ┌──────────────┐
│   前端缓存   │                 │   后端API    │
```

### 1. **前端题目缓存系统**

#### 1.1 题目加载策略

```typescript
// 前端题目缓存服务
class KnowledgeProblemCache {
  private cacheKey = 'knowledge_problems';
  private versionKey = 'cache_version';
  
  // 批量加载题目（一次请求获取所有）
  async loadAllProblems(category?: string) {
    const cacheVersion = localStorage.getItem(this.versionKey);
    const cachedData = localStorage.getItem(this.cacheKey);
    
    // 检查缓存是否最新
    if (cachedData && cacheVersion === await this.getLatestVersion()) {
      return JSON.parse(cachedData); // 使用缓存
    }
    
    // 批量请求所有题目
    const response = await fetch('/api/knowledge/problems/batch', {
      params: { category }
    });
    
    const problems = await response.json();
    
    // 存储到localStorage（持久化）
    localStorage.setItem(this.cacheKey, JSON.stringify(problems));
    localStorage.setItem(this.versionKey, problems.version);
    
    return problems;
  }
  
  // 获取单个题目（从缓存）
  getProblem(problemId: number) {
    const cached = localStorage.getItem(this.cacheKey);
    if (!cached) return null;
    
    const problems = JSON.parse(cached);
    return problems.data.find(p => p.problem_id === problemId);
  }
  
  // 获取题目列表（从缓存）
  getProblemsByCategory(category: string) {
    const cached = localStorage.getItem(this.cacheKey);
    if (!cached) return [];
    
    const problems = JSON.parse(cached);
    return problems.data.filter(p => p.category === category);
  }
}
```

#### 1.2 IndexedDB存储（大数据量）

```typescript
// IndexedDB存储服务（支持大数据量）
class KnowledgeIndexedDB {
  private dbName = 'KnowledgeDB';
  private storeName = 'problems';
  
  async initDB() {
    return new Promise((resolve, reject) => {
      const request = indexedDB.open(this.dbName, 1);
      
      request.onerror = () => reject(request.error);
      request.onsuccess = () => resolve(request.result);
      
      request.onupgradeneeded = (event) => {
        const db = event.target.result;
        const store = db.createObjectStore(this.storeName, { keyPath: 'problem_id' });
        
        // 创建索引加速查询
        store.createIndex('category', 'category', { unique: false });
        store.createIndex('subcategory', 'subcategory', { unique: false });
        store.createIndex('difficulty', 'difficulty', { unique: false });
      };
    });
  }
  
  async batchSave(problems: any[]) {
    const db = await this.initDB();
    const transaction = db.transaction([this.storeName], 'readwrite');
    const store = transaction.objectStore(this.storeName);
    
    // 批量存储
    problems.forEach(problem => store.put(problem));
    
    return new Promise((resolve, reject) => {
      transaction.oncomplete = () => resolve();
      transaction.onerror = () => reject(transaction.error);
    });
  }
  
  async getByCategory(category: string) {
    const db = await this.initDB();
    const transaction = db.transaction([this.storeName], 'readonly');
    const store = transaction.objectStore(this.storeName);
    const index = store.index('category');
    
    return new Promise((resolve, reject) => {
      const request = index.getAll(category);
      request.onsuccess = () => resolve(request.result);
      request.onerror = () => reject(request.error);
    });
  }
}
```

#### 2.1 选择题判题

```typescript
// 前端即时判题服务
class KnowledgeJudgeService {
  
  // 判断选择题答案
  judgeChoice(problem: any, userAnswer: string[]) {
    const correctOptions = problem.content.options
      .filter(opt => opt.correct)
      .map(opt => opt.id);
    
    const isCorrect = 
      userAnswer.length === correctOptions.length &&
      userAnswer.every(ans => correctOptions.includes(ans));
    
    return {
      correct: isCorrect,
      score: isCorrect ? 100 : 0,
      explanation: problem.explanation,
      correctAnswer: correctOptions
    };
  }
  
  // 判断判断题答案
  judgeJudge(problem: any, userAnswer: boolean) {
    const isCorrect = userAnswer === problem.content.answer;
    
    return {
      correct: isCorrect,
      score: isCorrect ? 100 : 0,
      explanation: problem.explanation
    };
  }
  
  // 判断填空题答案
  judgeBlank(problem: any, userAnswers: string[]) {
    const blanks = problem.content.blanks;
    let correctCount = 0;
    const results = [];
    
    blanks.forEach((blank, index) => {
      const userAns = userAnswers[index];
      const isCorrect = blank.acceptable.some(accept => {
        if (problem.content.case_sensitive) {
          return userAns === accept;
        } else {
          return userAns.toLowerCase() === accept.toLowerCase();
        }
      });
      
      if (isCorrect) correctCount++;
      results.push({ blankId: blank.id, correct: isCorrect });
    });
    
    const score = (correctCount / blanks.length) * 100;
    
    return {
      correct: score === 100,
      score: score,
      results: results,
      explanation: problem.explanation
    };
  }
}
```

### 3. **批量数据提交策略**

#### 3.1 答题数据缓存+批量提交

```typescript
// 答题数据提交服务
class KnowledgeSubmitService {
  private pendingKey = 'pending_solutions';
  private batchSize = 10; // 每10题提交一次
  private autoSyncInterval = 5 * 60 * 1000; // 5分钟自动同步
  
  // 保存答题结果到本地缓存
  saveSolutionLocally(problemId: number, answer: any, result: any) {
    const pending = JSON.parse(localStorage.getItem(this.pendingKey) || '[]');
    
    pending.push({
      problem_id: problemId,
      answer: answer,
      correct: result.correct,
      score: result.score,
      time_spent: result.time_spent,
      timestamp: Date.now()
    });
    
    localStorage.setItem(this.pendingKey, JSON.stringify(pending));
    
    // 达到批量大小自动提交
    if (pending.length >= this.batchSize) {
      this.batchSubmit();
    }
  }
  
  // 批量提交答题结果
  async batchSubmit() {
    const pending = JSON.parse(localStorage.getItem(this.pendingKey) || '[]');
    
    if (pending.length === 0) return;
    
    try {
      const response = await fetch('/api/knowledge/solutions/batch', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ solutions: pending })
      });
      
      if (response.ok) {
        // 清空本地缓存
        localStorage.removeItem(this.pendingKey);
      }
    } catch (error) {
      // 失败保留数据，下次继续提交
      console.error('批量提交失败:', error);
    }
  }
  
  // 启动自动同步
  startAutoSync() {
    setInterval(() => {
      this.batchSubmit();
    }, this.autoSyncInterval);
  }
}
```

### 4. **后端轻量级API设计**

#### 4.1 批量题目获取API（一次请求）

```typescript
// 批量题目API - 减少数据库查询
export async function GET(request: NextRequest) {
  const { searchParams } = new URL(request.url);
  const category = searchParams.get('category');
  const version = searchParams.get('version');
  
  // 检查版本号，如果一致直接返回空（减少传输）
  const currentVersion = await getVersion();
  if (version === currentVersion) {
    return NextResponse.json({
      version: currentVersion,
      data: null,
      message: '缓存已是最新版本'
    });
  }
  
  // 批量查询题目（一次性）
  const problems = await query(`
    SELECT 
      problem_id, title, category, subcategory,
      question_type, difficulty, content,
      knowledge_points
    FROM knowledge_problem
    WHERE defunct = 'N'
    ${category ? `AND category = ?` : ''}
    ORDER BY category, difficulty
  `, [category]);
  
  return NextResponse.json({
    version: currentVersion,
    data: problems,
    count: problems.length,
    timestamp: Date.now()
  });
}
```

#### 4.2 批量答题提交API

```typescript
// 批量答题提交API - 减少数据库写入次数
export async function POST(request: NextRequest) {
  const userId = getUserFromCookies(request)?.userId;
  if (!userId) {
    return NextResponse.json({ error: '未登录' }, { status: 401 });
  }
  
  const { solutions } = await request.json();
  
  // 批量插入答题记录（一次数据库操作）
  const values = solutions.map(sol => [
    sol.problem_id,
    userId,
    JSON.stringify(sol.answer),
    sol.correct,
    sol.score,
    sol.time_spent,
    new Date(sol.timestamp)
  ]);
  
  await query(`
    INSERT INTO knowledge_solution
    (problem_id, user_id, answer, correct, score, time_spent, submit_time)
    VALUES ?
  `, [values]);
  
  // 批量更新题目统计（一次数据库操作）
  await query(`
    UPDATE knowledge_problem
    SET 
      submit_count = submit_count + ?,
      correct_count = correct_count + ?
    WHERE problem_id IN (?)
  `, [
    solutions.length,
    solutions.filter(s => s.correct).length,
    solutions.map(s => s.problem_id)
  ]);
  
  return NextResponse.json({
    success: true,
    savedCount: solutions.length
  });
}
```

# 技术基础知识刷题系统设计方案

## 📋 系统概述

在原有算法题系统基础上，新增**技术基础知识题库**模块，支持编程语言、框架、数据库、前端、后端等技术领域的知识点练习。

## 🎯 功能特点

### 1. **题型分类**
- **算法题**（原有）：ACM竞赛、算法竞赛、数学题目
- **技术题**（新增）：编程语言、框架、数据库、系统设计等

### 2. **题型支持**
- **选择题**：单选、多选
- **判断题**：True/False
- **填空题**：代码补全、概念填空
- **简答题**：概念解释、系统设计

### 3. **答题方式**
- **即时反馈**：提交后立即显示答案和解析
- **无编译**：不需要编译运行，直接判题
- **学习模式**：可查看详细解析和知识点链接

## 🗃️ 数据库设计

### 新增表：`knowledge_problem` (知识题表)

```sql
CREATE TABLE knowledge_problem (
    problem_id SERIAL PRIMARY KEY,
    title VARCHAR(200) NOT NULL,
    category VARCHAR(50) NOT NULL,          -- 分类：language, framework, database, frontend, backend, system
    subcategory VARCHAR(50),                 -- 子分类：java, spring, mysql, react, etc
    question_type VARCHAR(20) NOT NULL,      -- 题型：choice, judge, blank, short
    difficulty INTEGER DEFAULT 1,            -- 难度：1-5
    
    -- 题目内容（JSONB存储）
    content JSONB NOT NULL,                  -- 题目内容（题目、选项、答案等）
    explanation TEXT,                        -- 答案解析
    knowledge_points JSONB DEFAULT '[]',     -- 知识点标签
    
    -- 元数据
    source VARCHAR(100),                     -- 来源
    author VARCHAR(48),                      -- 作者
    create_time TIMESTAMP DEFAULT NOW(),
    update_time TIMESTAMP DEFAULT NOW(),
    
    -- 统计
    submit_count INTEGER DEFAULT 0,
    correct_count INTEGER DEFAULT 0,
    
    defunct CHAR(1) DEFAULT 'N'
);

-- 创建索引
CREATE INDEX idx_knowledge_category ON knowledge_problem(category, subcategory);
CREATE INDEX idx_knowledge_type ON knowledge_problem(question_type);
CREATE INDEX idx_knowledge_content ON knowledge_problem USING GIN(content);
CREATE INDEX idx_knowledge_points ON knowledge_problem USING GIN(knowledge_points);
```

### 新增表：`knowledge_solution` (知识题答题记录)

```sql
CREATE TABLE knowledge_solution (
    solution_id SERIAL PRIMARY KEY,
    problem_id INTEGER NOT NULL,
    user_id VARCHAR(48) NOT NULL,
    answer JSONB NOT NULL,                   -- 用户答案
    correct BOOLEAN NOT NULL,                -- 是否正确
    score INTEGER DEFAULT 0,                 -- 得分
    
    submit_time TIMESTAMP DEFAULT NOW(),
    time_spent INTEGER DEFAULT 0,            -- 用时（秒）
    
    -- 学习数据
    review_time TIMESTAMP,                   -- 复习时间
    mastery_level INTEGER DEFAULT 0          -- 掌握程度：0-5
);

CREATE INDEX idx_knowledge_user ON knowledge_solution(user_id);
CREATE INDEX idx_knowledge_problem ON knowledge_solution(problem_id);
CREATE INDEX idx_knowledge_correct ON knowledge_solution(correct);
```

## 🔄 与算法题的区别

| 特性 | 算法题 | 知识题 |
|------|--------|--------|
| **判题方式** | 编译运行 | 即时比对 |
| **反馈速度** | 数秒到数分钟 | 即时（<1秒） |
| **题目类型** | 编程实现 | 选择/判断/填空/简答 |
| **学习方式** | 实践练习 | 知识记忆+理解 |
| **评分标准** | AC/WA/TLE | 正确率+知识点掌握 |
| **适用场景** | 竞赛、面试编程题 | 技术面试、日常学习 |

# 🚀 HUSTOJ 双端口运行指南

## 📋 端口分配

- **用户端**：http://localhost:3000
- **管理端**：http://localhost:3001

## 🛠️ 启动方式

### 方式1：使用启动脚本（推荐）

**Windows系统**：
```bash
cd f:\HUSTOJ\nextoj
start-dual.bat
```

**Linux/macOS系统**：
```bash
cd f:\HUSTOJ\nextoj
chmod +x start-dual.sh
./start-dual.sh
```

### 方式2：使用npm命令

**启动双端口**（同时启动用户端和管理端）：
```bash
cd f:\HUSTOJ\nextoj
npm run dev:dual
```

**单独启动用户端**：
```bash
npm run dev
# 访问：http://localhost:3000
```

**单独启动管理端**：
```bash
npm run dev:admin
# 访问：http://localhost:3001
```

### 方式3：手动启动（推荐，便于调试）

**终端1 - 用户端**：
```bash
cd f:\HUSTOJ\nextoj
npm run dev
# 访问：http://localhost:3000
```

**终端2 - 管理端**：
```bash
cd f:\HUSTOJ\nextoj
set NEXT_PRIVATE_STANDALONE_WORKER=true
set PORT=3001
npm run dev
# 访问：http://localhost:3001
```

**注意**：由于Next.js的安全机制，需要设置 `NEXT_PRIVATE_STANDALONE_WORKER=true` 环境变量来允许同一个应用目录启动多个实例。

## 🔐 登录入口

### 用户端登录
- 访问：http://localhost:3000
- 首页有明显的"登录系统"按钮
- 或直接访问：http://localhost:3000/login

- 访问：http://localhost:3001/admin/login
- 管理员专用登录入口（红色主题）
- 仅限administrator、contest_creator、problem_editor权限

## 🎨 界面差异

### 用户端 (3000端口)
- **导航栏**：题目、状态、排名、竞赛
- **首页**：登录按钮、开始做题、查看排名
- **主题色**：蓝色系（用户友好）
- **登录页**：http://localhost:3000/login

### 管理端 (3001端口)
- **导航栏**：控制台、题目管理、用户管理、比赛管理、权限管理
- **首页**：管理控制台
- **主题色**：红色系（管理标识）
- **登录页**：http://localhost:3001/admin/login

## 🔧 配置说明

### 端口配置
- 用户端默认端口：3000
- 管理端默认端口：3001
- 可通过环境变量修改：`PORT=3002 npm run dev`

### 环境变量
两个端口共享同一个 `.env.local` 配置文件：
- 数据库配置（PostgreSQL）
- JWT密钥
- OJ数据路径

## 🚀 生产环境部署

### 构建命令
```bash
# 构建用户端
npm run build

# 构建管理端
npm run build:admin
```

### 启动命令
```bash
# 启动用户端（生产模式）
npm run start

# 启动管理端（生产模式）
npm run start:admin
```

### Nginx反向代理配置示例
```nginx
# 用户端
server {
    listen 80;
    server_name your-oj-domain.com;
    
    location / {
        proxy_pass http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }
}

# 管理端
server {
    listen 80;
    server_name admin.your-oj-domain.com;
    
    location / {
        proxy_pass http://localhost:3001;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }
}
```

## ⚠️ 注意事项

1. **端口冲突**：
   - 确保3000和3001端口未被占用
   - 如有冲突，可修改端口配置

2. **数据库连接**：
   - 两个端口共享同一数据库
   - 数据库操作不会冲突

3. **会话管理**：
   - JWT token在两个端口都有效
   - 管理端登录会自动验证权限

4. **开发调试**：
   - 建议使用双终端方式便于调试
   - 可独立查看每个端口的日志

## 📞 故障排除

### 端口占用
```bash
# 检查端口占用（Windows）
netstat -ano | findstr :3000
netstat -ano | findstr :3001

# 检查端口占用（Linux）
sudo netstat -tulpn | grep 3000
sudo netstat -tulpn | grep 3001
```

### 启动失败
```bash
# 清理构建缓存
rm -rf .next node_modules
npm install
npm run dev:dual
```

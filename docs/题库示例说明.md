## 🚀 导入方法

### 方式1：使用管理端导入功能
1. 访问管理端：http://localhost:3000/admin/knowledge/import
2. 选择JSON格式
3. 上传示例JSON文件
4. 查看导入结果

### 方式2：使用API导入
```bash
curl -X POST http://localhost:3000/api/admin/knowledge/import \
  -H "Content-Type: application/json" \
  -d @examples/java-basics.json
```

### 方式3：数据库直接插入
```sql
INSERT INTO knowledge_problem (title, category, subcategory, question_type, difficulty, content, explanation, knowledge_points)
VALUES (
  'Java中String类的特点',
  'language',
  'java',
  'choice',
  2,
  '{"question":"以下关于Java String类的描述，哪些是正确的？","type":"multiple","options":[{"id":"A","text":"String是不可变的","correct":true},{"id":"B","text":"String可以被继承","correct":false}]}',
  'String是不可变的，存储在堆内存...',
  '["Java","String","不可变性"]'
);
```

## 📝 JSON格式要点

### 选择题格式
```json
{
  "title": "题目标题",
  "category": "language",
  "subcategory": "java",
  "question_type": "choice",
  "difficulty": 2,
  "content": {
    "question": "题目描述",
    "type": "single",  // single 或 multiple
    "options": [
      {
        "id": "A",
        "text": "选项文本",
        "correct": true  // 是否正确答案
      }
    ]
  },
  "explanation": "答案解析",
  "knowledge_points": ["知识点1", "知识点2"]
}
```

### 判断题格式
```json
{
  "title": "题目标题",
  "question_type": "judge",
  "content": {
    "question": "判断描述",
    "answer": true  // true 或 false
  },
  "explanation": "判断解析"
}
```

### 填空题格式
```json
{
  "title": "题目标题",
  "question_type": "blank",
  "content": {
    "question": "题目描述，用____表示空格",
    "blanks": [
      {
        "id": 1,
        "answer": "正确答案",
        "acceptable": ["答案", "answer"]  // 可接受的答案列表
      }
    ],
    "case_sensitive": false  // 是否区分大小写
  }
}
```

### 简答题格式
```json
{
  "title": "题目标题",
  "question_type": "short",
  "content": {
    "question": "问题描述",
    "keywords": ["关键词1", "关键词2"],  // 评分关键词
    "min_length": 100,  // 最小字数
    "max_length": 500,  // 最大字数
    "reference_answer": "参考答案",
    "auto_check": false  // 是否自动评分
  }
}
```

## 🎯 扩展建议

### 建议题库规模
- **Java语言**：50题（基础20题、进阶30题）
- **前端技术**：40题（React20题、Vue20题）
- **框架技术**：30题（Spring20题、其他10题）
- **数据库**：25题（MySQL15题、其他10题）
- **系统设计**：20题

### 建议难度分布
- **难度1**（入门）：20%
- **难度2**（基础）：30%
- **难度3**（中级）：30%
- **难度4**（高级）：15%
- **难度5**（专家）：5%

### 建议题型分布
- **选择题**：50%（快速刷题）
- **判断题**：20%（概念验证）
- **填空题**：20%（代码补全）
- **简答题**：10%（深度理解）

## 💡 制作题库建议

1. **参考官方文档**：技术栈官方文档最权威
2. **结合实际经验**：真实项目中的常见问题
3. **面试题参考**：各大厂面试题精选
4. **知识点覆盖**：确保技术栈核心知识点全覆盖
5. **难度递进**：从基础到高级循序渐进
